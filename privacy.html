Polityka prywatności

HB File Tools jest prywatnym narzędziem do obsługi kopii zapasowych właściciela konta Google. Projekt prowadzi HubertBe.

Ostatnia aktualizacja: 25 września 2026.

1. Dane i cel dostępu

Narzędzie korzysta z metadanych plików i folderów oraz z zawartości plików potrzebnych do przesyłania, sprawdzania i odtwarzania kopii. Może tworzyć, odczytywać, aktualizować i usuwać pliki kopii zgodnie z konfiguracją właściciela oraz udzielonymi uprawnieniami.

Zgoda OAuth może obejmować cały Google Drive, a nie tylko folder backupu. Ograniczenie zadań do wskazanych lokalizacji wynika z konfiguracji narzędzia. Zakres uprawnień należy sprawdzić na ekranie zgody Google.

2. Przechowywanie i ochrona

Skonfigurowany proces backupu szyfruje zawartość i nazwy plików kopii przed przesłaniem do Google Drive. Podczas przygotowania kopii oraz odtwarzania na urządzeniach właściciela mogą powstawać lokalne dane niezaszyfrowane. Tokeny OAuth i klucze szyfrowania są przechowywane w chronionej konfiguracji zarządzanych urządzeń; nie są częścią tej strony.

Google przechowuje wysłane kopie i obsługuje autoryzację. Urządzenia i serwery skonfigurowane przez właściciela wykonują zadania backupu. Dane nie są wykorzystywane przez HB File Tools do reklam ani sprzedaży informacji o użytkownikach.

3. Retencja i usuwanie

Czas przechowywania i usuwanie kopii zależą od konfiguracji właściciela. Dokument nie ustanawia jednego okresu retencji. Istniejące kopie można usunąć w Google Drive lub poprzez świadomie uruchomioną operację narzędzia; lokalne pliki i kopie odtworzone wymagają osobnego usunięcia.

4. Cofnięcie dostępu

Dostęp można odwołać w ustawieniach połączeń konta Google. Może to zatrzymać kolejne zadania backupu. Cofnięcie dostępu samo w sobie nie usuwa już utworzonych kopii ani lokalnej konfiguracji.

5. Ta strona internetowa

Strona jest hostowana przez GitHub Pages. Jej kod nie zawiera formularzy, analityki, reklam, skryptów ani zewnętrznych fontów. GitHub może przetwarzać dane techniczne połączeń zgodnie ze swoją polityką prywatności. Backupy i tokeny OAuth nie są przesyłane do tej strony.

6. Kontakt i informacje

Informacje o opiekunie projektu: profil HubertBe. Pytania ogólne: repozytorium HB File Tools. Publiczne zgłoszenia nie powinny zawierać plików prywatnych, tokenów, haseł ani danych osobowych.

Dokumentacja dostawców: Google API Services User Data Policy oraz szyfrowanie rclone.
